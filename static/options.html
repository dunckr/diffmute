diffmute

Glob rules for files to collapse or hide on GitHub pull request diffs. A pattern without / matches the file name at any depth, **/ matches any number of folders, and a leading / anchors to the repo root. The first matching category wins.

Review flow

Files you have scrolled through or marked viewed are remembered per pull request. On your next visit, files whose changes are the same are collapsed and new or changed files get a badge.

Groups files so types and schema come first, then logic, UI, tests and config. Authors can pin files by adding a "Review order" heading followed by a list of paths to the pull request description.

] next file to review, [ previous, v mark viewed and go to next, x collapse or expand, h help.

Reading order tiers

Files matching none of these are read as logic, after types and schema.

Never mute

Globs for files that are never muted in any repo. A line starting with ! takes a path back out, in this list and in category patterns.
